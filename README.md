> Неофіційний експериментальний міст CAPT для Canon LBP-1120 і Windows 11 x64.
> Перевірено на одному ПК; чисте встановлення на іншому ПК ще не перевірене.

## Збірка з вихідного коду

Потрібні Windows x64, .NET Framework 4.x і w64devkit 2.11.0.
Розпакуйте w64devkit у `tools/w64devkit`, щоб існував `tools/w64devkit/bin/g++.exe`.
У PowerShell з каталогу проєкту виконайте послідовно:

```powershell
.\build.ps1
.\build-bridge.ps1
.\build-setup.ps1
```

Інсталятор: `dist/Canon-LBP1120-x64-Setup.exe`.
Інструкція встановлення: [PACKAGE-README.txt](PACKAGE-README.txt).
Вихідний код libcapt та його ліцензія збережені в `upstream`.
Компілятори, готові EXE, журнали й документи користувача не входять до репозиторію.

## Опис перевіреної локальної конфігурації
# Canon LBP-1120 у Windows 11 x64

Встановлено системний принтер **Canon LBP-1120 x64**. Його можна вибирати
через Ctrl+P у Windows-застосунках. Штатний Microsoft IPP Class Driver передає
завдання локальному мосту CAPT, який друкує через `usbprint.sys`.
Віртуальна машина й інший комп'ютер не потрібні. Оригінальний 32-бітний
драйвер Canon не встановлюється.

Інструкція для системної черги: [SYSTEM-PRINTING.md](SYSTEM-PRINTING.md).
Нижче описано запасний спосіб прямого друку PDF і зображень.

## Використання

1. Увімкніть Canon LBP-1120, під'єднайте USB та завантажте папір A4.
2. Запустіть `Print-LBP1120.cmd` і виберіть PDF або зображення.
   Також можна перетягнути один файл на `Print-LBP1120.cmd`.
3. З Word, браузера чи іншого застосунку спочатку збережіть документ як PDF,
   потім відкрийте його через цю програму.

Параметри: A4, 600 dpi, одна копія, до 100 сторінок за один запуск.
Книжкова орієнтація; альбомні сторінки вписуються на книжковий аркуш.
Поля приблизно 3,4 мм зліва та 5,1 мм зверху; зображення вписується
в область 4800×6768 пікселів. Кольори переводяться в чорно-біле з раструванням.
Для багатокадрових TIFF друкується лише перший кадр.
Двосторонній друк, вибір діапазону сторінок і автоматичний повтор після помилок
не реалізовані. Один запуск друкує весь вибраний PDF.

Для скасування натисніть Ctrl+C у вікні програми. Уже прийнята принтером
сторінка може все одно вийти. Якщо зв'язок USB перервався, вимкніть і знову
увімкніть принтер перед повторним запуском. Не запускайте старі утиліти Canon
одночасно з цією програмою.

## Перевірки

- `capt-status.exe`: версія протоколу й стан, без друку.
- `capt-print.exe --selftest`: стискання та зворотне декодування чотирьох
  типів растра, без звернення до принтера.
- `capt-print.exe --verify-pbm file.pbm`: перевірка і стискання PBM, без друку.
- `capt-print.exe --print-pbm file.pbm`: друк підготовленого растра.

Журнали спроб через `Print-Document.ps1` розташовані в `logs`.
Тимчасовий растр документа видаляється після завершення обробки.

## Основа й збірка

Протокол CAPT і стискання SCoA: https://github.com/darkvision77/libcapt

Використана ревізія: `8f1fd502e6fee893d409f09c5895248c189ead4b`.
Ліцензія BSD-2-Clause міститься в `upstream/LICENSE`.
Код бібліотеки збережено в `upstream/libcapt`; `Config.hpp` генерується під час збірки.
Оригінальні DLL Canon не змінювалися й не входять у програму.

`build.ps1` збирає програми за допомогою локального w64devkit 2.11.0.
Перетворення PDF використовує `Windows.Data.Pdf`, зображень — .NET System.Drawing.
Програма не потребує встановлення компілятора для звичайного використання.
