# Системний принтер Canon LBP-1120 x64

## Як друкувати

1. Підключіть і ввімкніть Canon LBP-1120, покладіть папір A4.
2. Відкрийте документ у Word, браузері чи іншому Windows-застосунку.
3. Натисніть Ctrl+P і виберіть **Canon LBP-1120 x64**.

Зберігати документ у PDF перед друком через цей принтер більше не потрібно.
Підтримуються A4, 600 dpi, чорно-білий односторонній друк, одна копія завдання.
Максимум 100 сторінок і 128 МіБ переданого документа за одне завдання.
Windows зазвичай передає PWG Raster; міст також приймає PDF та JPEG через IPP.

Міст запускається у фоні після входу цього користувача у Windows.
Для ручного запуску є `Start-Bridge.cmd`.
Не переміщуйте цю папку: на неї посилається автоматичний запуск.
До входу користувача або коли міст закритий, цей принтер недоступний.
Системне меню поки не показує фактичний стан USB-принтера в режимі очікування;
помилки обладнання визначаються під час виконання завдання.

## Скасування та помилки

Завдання можна скасувати у звичайній черзі друку Windows. Скасування
перевіряється під час передавання й очікування; уже прийнятий принтером аркуш
може все одно вийти. Під час перетворення документа скасування набуває дії
після завершення перетворення.

У разі помилки завдання не повторюється автоматично самим мостом.
Перед повторним друком перевірте, які сторінки вже вийшли, щоб не отримати
дублікати. Незавершені локальні файли після аварійного завершення також
не друкуються автоматично. Windows може окремо запропонувати повтор завдання.

Журнал: `bridge.log`. Тимчасові файли завдання: підпапка `queue`.
Після звичайного завершення або обробленої помилки документи з `queue`
видаляються; після аварійного завершення файли можуть залишитися.
Не очищуйте `queue`, поки виконується завдання.

За потреби запасний прямий друк PDF працює через `Print-LBP1120.cmd`.
Не запускайте його одночасно зі сторонніми утилітами, які працюють із Canon.

## Реалізація

`Windows application -> Microsoft IPP Class Driver -> 127.0.0.1:8631 -> PWG/PDF -> PBM -> CAPT -> usbprint.sys -> LBP-1120`

Це системна черга зі штатним підписаним драйвером Microsoft та власним
користувацьким мостом x64. Це не модифікація DLL Canon й не новий драйвер ядра.
Міст слухає лише IPv4 loopback, тому комп'ютер не відкриває принтер для локальної
мережі. Окремі правила брандмауера та вимкнення перевірки підпису не потрібні.

Для перевстановлення: запустіть міст, потім із PowerShell адміністратора
виконайте `Install-SystemPrinter.ps1`. Скрипт перевіряє ім'я вже наявного
принтера та очікуваний драйвер. Не змінює принтер за замовчуванням.
Для видалення черги й автозапуску: `Uninstall-SystemPrinter.ps1` із правами
адміністратора. Файли програми та журнали залишаються на диску.

## Перевірки

- Протокол IPP: можливості принтера, перевірка параметрів, Print-Job,
  Create-Job/Send-Document, стан завдання, скасування, chunked HTTP.
- PWG Raster: декодування повторів рядків і пікселів, полярність чорного,
  відхилення обрізаного потоку.
- Windows: двосторінковий PrintDocument через системний IPP-драйвер пройшов
  повний шлях і фізично надрукував обидва аркуші; підтверджено користувачем.
- Стан «лоток спорожнів після останнього аркуша»: додана регресійна перевірка
  за телеметрією отриманого двосторінкового завдання. Виправлення цього
  конкретного стану після збірки ще не перевірялося повторним фізичним друком.
- Аварійне завершення, перезапуск Windows та скасування під час фізичного
  друку ще потребують окремої перевірки.

`Test-SystemQueue.ps1` за замовчуванням вимагає режим `--dry-run` у моста
і не друкує папір. Фізичний тест запускається лише з явним параметром `-Physical`.
`bridge-tests.exe` також відмовляється працювати, якщо міст не в режимі dry-run.

Основні джерела: [Microsoft IPP Class Driver](https://learn.microsoft.com/universal-print/fundamentals/universal-print-connector-with-ipp),
[PWG Raster 5102.4](https://ftp.pwg.org/pub/pwg/candidates/cs-ippraster10-20120420-5102.4.pdf),
[libcapt](https://github.com/darkvision77/libcapt).
