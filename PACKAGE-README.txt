Canon LBP-1120 x64 — CAPT Bridge 0.1.0

Призначення: Windows 11 x64, Canon LASER SHOT LBP-1120 через USB.
Windows 10 та Windows ARM64 окремо не перевірені й не заявляються як підтримувані.

ВСТАНОВЛЕННЯ
1. Скопіюйте Canon-LBP1120-x64-Setup.exe на потрібний комп'ютер.
2. Підключіть принтер через USB та ввімкніть його.
3. Запустіть EXE, натисніть «Встановити», підтвердьте UAC Windows.
4. У Word, браузері чи іншому застосунку виберіть через Ctrl+P:
   Canon LBP-1120 x64.

Папка програми: %LOCALAPPDATA%\CanonLBP1120
Програма додає автозапуск для користувача, який запускає інсталятор.
Міст працює після входу цього користувача у Windows.
Для ручного запуску: Start-Bridge.cmd у папці програми.

ПАРАМЕТРИ Й ОБМЕЖЕННЯ
A4, 600 dpi, чорно-білий односторонній друк, одна копія за завдання.
До 100 сторінок і 128 МіБ документа за завдання.
Це штатний Microsoft IPP Class Driver плюс локальний міст CAPT x64.
Оригінальні DLL Canon не встановлюються, новий драйвер ядра не додається.
Інсталятор не завантажує залежності з інтернету, але потрібні штатні компоненти
друку Windows і .NET Framework 4.x. На незвичних конфігураціях Windows
встановлення або робота можуть вимагати додаткової перевірки.
Міст слухає лише 127.0.0.1:8631. Принтер не публікується в локальну мережу.
Не переміщуйте папку після встановлення.

ПОВТОРНЕ ВСТАНОВЛЕННЯ
Пакет не замінює іншу активну копію моста й не перезаписує наявний принтер
з таким самим ім'ям. Спочатку видаліть попередню версію.
Якщо після видалення залишилися журнали у %LOCALAPPDATA%\CanonLBP1120,
перенесіть цю папку перед наступним встановленням.

ВИДАЛЕННЯ
Параметри Windows → Програми → Встановлені програми →
Canon LBP-1120 x64 (CAPT Bridge) → Видалити.
Або запустіть Uninstall.exe у папці програми.
Завершіть або скасуйте завдання перед видаленням.
Журнали й файли незавершених завдань залишаються для діагностики.

ПЕРЕВІРКА
Друк PDF і двосторінковий друк через системну чергу перевірені на вихідному ПК.
Вихід обох аркушів підтверджено користувачем.
Інсталятор перевірено складанням і перевіркою розпакування пакета.
Чисте встановлення на іншому ПК поки не перевірене.
